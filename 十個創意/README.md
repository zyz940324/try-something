# Desktop-X Pro v5.9: 模組化 AI 智慧工作站

Desktop-X Pro 是一個專為提升個人生產力而設計的整合式智慧儀表板。它結合了 Flask 後端強大的分析能力與前端流暢的現代化 UI，為使用者提供一站式的自動化工作環境。

---

## 🌟 核心功能亮點

### 1. 🚀 一鍵啟動工作模式
- 自訂工作分組（Gmail, GitHub, Calendar, Line 等）。
- 支援多網址同步開啟，快速進入工作環境。

### 2. 🎙️ 專業逐字稿助手
- 支援實時語音錄製與本地存檔。
- 自動化管理逐字稿紀錄，方便日後查閱。

### 3. 📖 學習速讀機器人
- 輸入網址即可進行 AI 深度解析。
- 提供「標題概覽」、「核心關鍵字」與「重點精華提取」。

### 4. 🔎 語義檔案檢索
- 深度遍歷桌面（Desktop）與子目錄檔案。
- AI 智慧評分一致性，協助快速定位零散文件。

### 5. ⚡ 進階系統診斷 (Advanced Monitor)
- **多維度監控**: 實時追蹤 CPU、**記憶體 (RAM)** 與硬碟使用率。
- **網路流量分析**: 即時顯示上傳/下載速度 (KB/s, MB/s)，揪出背景耗能程式。
- **智慧負載預警**: 監控條根據負載自動變色（綠色 < 70% < 橙色 < 90% < 紅色）。
- **資源怪獸榜**: 綜合計算 CPU 與 Memory 權重，精確捕捉真正的系統負擔者。

### 6. 🕒 時間感知主題 (Morning/Afternoon/Night)
- 根據目前時段自動切換色彩主題（清晨藍、夕陽橘、專業黑）。
- 動態顯示時段符號（☀️, ⛅, 🌙）。

### 7. 🌌 生產力音樂氛圍
- 內建 Lofi、鋼琴、環境流動等多種專注音樂。
- 支持雨聲、森林等大自然環境音效切換。

### 8. 🎯 待辦事項管理
- 極簡化 Task 清單，支援快速新增、標記完成與刪除。
- 與本地緩存同步，不怕資料丟失。

---

## 🛠️ 技術架構

- **前端**: Vanilla JS, CSS3 (Glassmorphism), HTML5.
- **後端**: Python Flask (統一服務埠: 8000).
- **自動化**: PowerShell 5.1+ (v5.9 Zero-Touch Edition)。
- **AI 邏輯**: 內部語義分析引擎與網頁爬蟲技術。

---

## 📥 快速啟動

1. **環境需求**: Python 3.8+ 與 PowerShell。
2. **啟動說明**: 在專案目錄下直接雙擊執行 `Start-Dashboard.bat`。
   - 這是最建議的啟動方式，它會自動處理權限要求並呼叫 PowerShell 核心功能。
   - 第一次啟動時會出現一個安裝視窗（同步環境中），請稍等其自動關閉。
   - 若儀表板未自動開啟，請嘗試手動在瀏覽器輸入 `http://127.0.0.1:8000`。

### 常見啟動排除
- **提示 Port 8000 佔用**: 代表伺服器已在背景執行，腳本會自動嘗試為您重新開啟瀏覽器分頁。
- **權限請求**: 啟動時若出現管理員權限請求（UAC），請點選「是」。
3. **瀏覽存取**: 開啟瀏覽器訪問 `http://localhost:8000`。
